# 短链创建运行时策略

管理员可在“设置 → 短链创建默认策略”维护默认短域名、跳转状态码、自动短码长度与字符集、保留短码、禁用关键词、默认有效期、默认点击上限和 HTTPS 强制策略。

创建链接时，Platform API 会实时读取 `system_settings`，无需重启服务：

- 调用方未传域名、状态码、有效期或点击上限时使用管理员默认值；显式传值继续优先。
- 自动生成短码使用配置的长度和字符集；手工短码同样接受字符集、保留词和禁用词检查。
- 开启强制 HTTPS 后，HTTP 或非完整目标地址会在写入数据库前被拒绝。
- 默认短域名仍必须通过工作区自定义域名的已验证检查，设置不能绕过租户权限。

设置 API 对跳转状态码、数值范围和安全 ASCII 字符集执行服务端校验。数组字段以 JSON 数组存储，管理界面负责将逗号分隔输入转换为数组。
