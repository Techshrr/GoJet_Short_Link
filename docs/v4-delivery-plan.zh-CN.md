# GoJet V4 交付边界与执行清单

本文把产品愿景转换为可逐项验收的工程交付，不以“路由能打开”或静态演示数据作为完成标准。

## 当前仓库事实

仓库从单个 `LICENSE` 文件开始重建，已经具备跳转、实时统计、Analytics Worker、邮件、设置、
工作区、三个前端表面和部署工具的可运行基础，但完整 V4 仍未通过全部生产验收。逐领域已完成、
部分完成和缺失项目以 [`v4-status.zh-CN.md`](v4-status.zh-CN.md) 为准；不得再使用本计划的阶段
标题推断某个模块已经完成。

## 锁定执行顺序与验收门

每一阶段必须通过本阶段的自动化和真实数据验收，才能进入下一阶段。后续阶段可以建立设计稿，
但不得把没有后端闭环的入口发布为可用功能。

| 阶段 | 可交付范围 | 阶段验收门 |
| --- | --- | --- |
| 1. 数据与统计 | 数据库迁移、Redis 原子计数、Stream consumer group、MySQL 批量落库、失败重试、定时对账、限流与 Bot 分类 | 真实 Redis/MySQL 集成测试；访问 10 次后点击为 10；Worker 停止与恢复不丢事件；Direct、Referer、Unknown、Bot 可区分 |
| 2. 邮件 | 加密 SMTP 配置、连接测试、测试邮件、验证邮件队列、日志、重试与脱敏错误 | 可控 SMTP 测试服务器端到端测试；失败不返回 500；成功保存 Message-ID |
| 3. 设置 | 基础信息、品牌文件、SEO、注册认证、短链、隐私、存储和维护设置 | Logo 真实上传/替换/删除；公开 URL 可访问；缓存刷新；前台 SEO 与品牌即时生效 |
| 4. 用户 SaaS | 独立用户布局、真实总览、链接数据表、分步创建、分析中心、活动/文件夹/标签 | API 与浏览器测试覆盖筛选、分页、批量操作、CSV 和自定义日期；所有指标来自真实事件 |
| 5. 工作区 | 工作区切换、邀请生命周期、五级角色、权限策略和审计 | 待接受、接受、过期、撤销、重发、改角色、移除均有权限测试与审计记录 |
| 6. 管理后台 | 独立路由和布局；用户、资源、风控、运营、系统管理 | 管理员权限隔离；危险操作二次确认；每次变更产生管理员审计日志 |
| 7. 公开网站 | 完整导航、独立产品页面、解决方案、资源、定价、关于、联系及状态页面 | 每个产品页均有独立 Hero、界面展示、场景、流程、安全、套餐、FAQ 与 CTA；不使用换标题的通用页冒充独立内容 |
| 8. 设计系统 | 三套产品表面的 token、组件、状态和响应式规范 | 1440、1024、768、390 四档截图回归；加载、空、错误和危险状态一致 |
| 9. 自动验收 | API、权限、Playwright、安全与迁移测试 | 注册至统计的主链路全绿；SQL 注入、XSS、CSRF、越权和上传策略有测试 |
| 10. 部署 | Docker、Nginx、安装、升级、回滚、队列、Scheduler、备份文档与发布包 | 全新环境一键安装；升级保留旧数据；回滚演练；健康检查和告警可用 |

## 需要项目所有者提供的输入

工程可以在采用合理默认值的情况下继续推进，不需要逐页面监督；但以下内容不能由开发者伪造，
必须在相应阶段验收前提供：

1. **现有生产数据与兼容要求**：旧版本数据库结构、迁移样本（脱敏即可）、需要保留的短码、
   域名和配置。没有这些数据只能验证全新安装，不能承诺“旧数据不丢失”。
2. **GoJet 品牌资产**：主/深色/浅色/方形 Logo、Favicon、PWA 图标、默认分享图、字体授权、
   品牌色与商标使用规则。没有最终资产时只能使用明确标注的临时占位资源。
3. **真实产品截图或可生成截图的产品环境**：公开产品页要求展示实际界面，不能复制 S.EE
   的截图或商标资产。
4. **基础设施参数与密钥**：生产域名、DNS/Cloudflare 权限、SMTP 凭据、对象存储、MySQL、
   Redis、Turnstile、邮件发件域名及 TLS/SSL 策略。密钥只能通过 Secret 管理提供，不能提交仓库。
5. **业务与合规决策**：套餐/配额/价格、数据保留期、Cookie 策略、允许地区、滥用处理流程、
   文件大小与类型限制、IP/Referer 保存规则以及隐私政策文本。
6. **GitHub 写入能力**：仓库 remote 或可推送凭据、PR 创建权限和 Actions 读取权限。只有本地
   Git 与 PR 元数据工具时，无法把分支推送至 GitHub，也无法查看远端 Actions 日志。

## 可以由工程默认并后续修改的内容

在项目所有者未指定时，可先采用：Go 1.23、Redis 7.4、MySQL 8、UTC、中文默认界面、
302 默认跳转、SHA-256/HMAC 访客标识、30 天原始事件保留、Owner/Admin/Editor/Analyst/Viewer
五级角色，以及独立的公开站、用户控制台和管理后台前端应用。所有默认值都必须进入设置或部署
配置，不能硬编码成不可迁移的产品规则。

## 完成定义

“完成 GoJet V4”表示上表十个阶段全部通过验收门、迁移和回滚经过演练、生产配置由项目所有者
确认，并生成可复现的发布包。单个阶段或 PR 完成时，只报告该阶段实际通过的项目；不会将后续
规划表述为已经实现。
