# 套餐、订阅与账单闭环

GoJet V4 使用“账单申请 → 管理员核验收款 → 原子切换订阅”的可审计流程。在未接入具体支付服务商前，不伪造支付成功：用户提交的账单保持“待确认”，只有具备 `settings.manage` 权限的管理员填写处理备注并确认后，套餐和配额才会生效。

## 生命周期

1. 工作区所有者或管理员选择购买、变更或续费套餐。
2. 平台在事务中锁定工作区订阅，拒绝并行的待处理账单，并生成不可预测的唯一账单号。
3. 管理员核对外部收款记录，填写备注，将账单标记为已支付或作废。
4. 已支付的购买或变更账单立即切换套餐并建立 30 天周期；续费账单从当前有效周期末尾继续增加 30 天，不会损失剩余天数。
5. 到期未处理账单自动对账为逾期。用户可以设置“周期末取消”，到期对账后订阅变为已取消。
6. 请求、付款、作废、取消与撤销取消均写入 `subscription_events`；管理员 API 请求同时进入管理员审计日志。

所有配额检查继续读取 `workspace_subscriptions` 当前生效套餐，因此支付前不会提前获得资源，确认支付后新配额立即用于短链接、二维码、文本、个人主页、文件和团队成员创建。
