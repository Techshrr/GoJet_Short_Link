# GoJet V4 Release Acceptance Checklist

完成的含义是“真实闭环通过”，不是页面存在或按钮可点击。

## A. 自动化门禁

以下项目由 `.github/workflows/ci.yml` 在当前提交执行；只有 GitHub 显示绿色才能勾选：

- [ ] PHP 8.4 锁定依赖安装成功
- [ ] 全新 SQLite 测试数据库迁移成功
- [ ] Laravel Pint 无格式问题
- [ ] 全部 PHPUnit Feature Tests 通过
- [ ] `npm ci` 与 Vite 生产构建通过
- [ ] Go `gofmt`、`go test -race`、`go vet`、静态构建通过

本地无数据库扩展环境可执行：

```bash
bash scripts/validate-release.sh
```

它验证 PHP 语法、路由、Blade 编译、Go 单测/race/vet/build、Shell 语法、必需资产及虚构营销数字扫描。

## B. 公开网站

- [ ] 首页在 1440、1024、768、390 宽度无横向溢出
- [ ] 产品页不是只替换标题的空模板，每页有独立 Hero、能力、场景、流程、FAQ 与 CTA
- [ ] 解决方案、定价、开发者、API、状态、更新日志、关于和合规页完整
- [ ] Mega Menu、移动导航、登录和注册入口可用
- [ ] 不展示未经证实的客户 Logo、评分、用户量或访问量
- [ ] 页面标题、描述、Canonical、OG 图与 Favicon 来自设置中心

## C. 用户控制台

- [ ] 总览只展示真实数据
- [ ] 链接搜索、筛选、分页、创建、编辑、暂停、恢复、归档和批量操作可用
- [ ] 密码、有效期、最大点击、UTM、智能路由和自定义域名真实生效
- [ ] 活动、文件夹和标签具有可查询的真实关联
- [ ] 工作区可创建和切换
- [ ] 邀请具有待接受、已接受、过期、撤销、重发状态
- [ ] 非匹配邮箱不能接受邀请
- [ ] 所有者、管理员、编辑者、分析员和只读角色权限符合矩阵
- [ ] 空状态、错误状态、成功状态和危险操作确认统一

## D. 管理后台

- [ ] 后台使用独立布局和导航，不混入用户侧边栏
- [ ] 平台概览读取真实用户、工作区、链接、点击、失败和举报数据
- [ ] 用户、工作区、链接、文本、文件、主页、套餐和 Webhook 可检索治理
- [ ] 隔离、恢复、封禁、角色变更和危险操作记录审计日志
- [ ] 系统诊断显示数据库、Redis、队列、Scheduler、SMTP、统计失败和 Go spool 状态

## E. 系统设置

- [ ] 网站名称、简称、标语、描述、联系方式、公司和页脚保存后立即生效
- [ ] Logo、深浅色 Logo、方形图标、Favicon、邮件 Logo 和 OG 图可上传、预览、替换和删除
- [ ] 默认 SEO 与页面元信息生效
- [ ] 注册、邮箱验证、密码、Turnstile 和登录策略生效
- [ ] 默认短链域名、跳转码、短码长度、保留词、有效期和安全策略生效
- [ ] 统计保留、Referer、城市、机器人和对账策略生效
- [ ] 维护模式对管理员豁免、对普通访问者生效
- [ ] 后台路径修改具有回滚保护

## F. 点击与分析真实闭环

- [ ] Laravel 跳转一次后，`click_events`、`links.clicks_count` 和日聚合在同一请求完成
- [ ] 停止 Laravel 默认队列 Worker 后，核心点击仍记录
- [ ] Go 跳转先生成 spool 文件，再返回 3xx
- [ ] 控制面临时不可用时，spool 文件保留并在恢复后投递
- [ ] 相同 `event_uuid` 重放只生成一条事件
- [ ] spool 目录不可写时 Go 返回 503，Nginx 回退 Laravel
- [ ] Direct、Unknown、Referral、Search、Social、Campaign 和 Internal 分类正确
- [ ] 相同访客同一链接同一天只计算一次独立访客
- [ ] 机器人保留但不污染独立访客（开启策略时）
- [ ] 来源、设备、浏览器、系统、国家、地区、城市、语言、UTM 和目标分流可核对
- [ ] `gojet:analytics:reconcile --dry-run` 和正式对账结果正确
- [ ] CSV 导出与页面统计一致

## G. 邮件真实闭环

- [ ] 未配置 SMTP 时发送验证邮件不返回 500
- [ ] SMTP 测试失败时显示诊断，且不能开启强制验证
- [ ] SMTP 测试成功后保存验证状态
- [ ] 注册验证、密码重置和工作区邀请真实送达
- [ ] `email_delivery_logs` 保存类型、收件人、状态、尝试次数和错误
- [ ] 后台重试失败邮件成功
- [ ] 邮件日志写入失败不会遮蔽原始传输异常

## H. 部署与恢复

- [ ] Docker Compose 全新安装通过
- [ ] 传统 Debian/Ubuntu 全新安装通过
- [ ] V3 数据库升级到 V4 后用户、工作区、链接、域名和历史点击保留
- [ ] Nginx 仅把根级短码交给 Go；其他页面进入 Laravel
- [ ] `gojet-redirector`、Scheduler 和 Worker 重启后自动恢复
- [ ] `/up` 和 Go `/healthz` 正常
- [ ] MySQL、Redis 和 Go 8081 不暴露公网
- [ ] 数据库、私有存储和 spool 完成加密备份
- [ ] 在隔离环境执行一次恢复并访问样例短链
- [ ] 完成一次升级回滚演练
