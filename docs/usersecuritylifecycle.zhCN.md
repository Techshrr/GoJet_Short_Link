# 用户安全生命周期

管理员的“用户与封禁”页面现在提供独立安全详情，而不是只在列表中放置状态下拉框：

- 查看邮箱验证状态、有效会话数、所属工作区和角色；
- 查看每个登录会话的指纹、IP、客户端、最后活动和到期时间；
- 单独撤销一个浏览器会话；
- 人工标记或撤销邮箱验证，必须填写依据并写入审计；
- 强制密码重置时立即撤销全部会话，旧重置令牌同时失效；
- 重置链接只通过可诊断邮件队列发送，令牌仅以 SHA-256 摘要保存，30 分钟到期且只能使用一次；
- 新密码使用 bcrypt cost 12 保存，完成重置后再次撤销残留会话。

管理员永远不能读取用户原密码，也不会在 API 中获得临时密码。
