# GoJet V4 产品重构基线

本分支是一次产品级重构，不是 RC7 的补丁升级。

## 发布与安装原则

- 只支持全新安装。
- 推荐使用全新站点目录与全新 MySQL 数据库。
- 不承诺 RC1–RC7 数据库或文件结构的原地升级兼容。
- 生产发布包不携带 `upgrade.sh`、`upgrade-native.sh` 或 `rollback.sh` 作为用户入口。
- 安装验收以“空目录 + 空数据库 + 宝塔 aaPanel + Nginx + PHP 8.3 + MySQL 8 + Redis + systemd”为主要路径。

## 管理员模型

- 后台业务操作取消 step-up/二次验证。
- TOTP 仅作为管理员登录阶段的可选双因素认证。
- 超级管理员拥有全部权限，不受普通权限表限制。
- 其他管理员使用显式权限集合，可从运营、客服、安全、只读等模板创建，也可自定义。
- 用户、链接、文件、公告、邮件、设置等资源管理必须提供与权限相匹配的真实操作能力，而不是只读展示。

## 用户账户体系

公开路由：

- `/login`
- `/register`
- `/forgot-password`
- `/reset-password`
- `/verify-email`

用户控制台：

- `/app/`
- `/app/dashboard`
- `/app/links`
- `/app/text`
- `/app/files`
- `/app/bio`
- `/app/domains`
- `/app/analytics`
- `/app/settings`

未登录访问 `/app/*` 时跳转 `/login?redirect=...`。登录页不再挂在 `/app`。

## 用户管理最低能力

- 搜索、筛选、查看详情
- 管理员手动创建用户
- 编辑显示名称和邮箱
- 修改邮箱验证状态
- 启用、封禁、解除封禁
- 发送密码重置邮件
- 强制退出全部会话或单个会话
- 查看工作区与资源统计
- 删除用户（采用安全删除/匿名化策略）

## 公告与邮件

- 公告使用 Markdown 编辑器和预览，不使用 `prompt()`。
- 公告支持草稿、发布、定时发布、编辑、归档、删除。
- 邮件模板支持主题、HTML/Markdown 内容、变量提示、预览、测试发送与保存。
- 保存公告、SMTP、邮件模板等普通内容管理操作不要求二次验证。

## 运维交互

下列动作不再强制填写“执行原因/变更原因”：

- 平台对账
- 清理应用缓存
- 开启或关闭维护模式

操作仍记录服务器自动生成的审计日志，包括管理员、时间、IP、动作和结果。

## 前台设计

营销站、认证页、用户控制台和管理员后台作为四套明确界面重新设计。营销站参考 S.EE 的产品信息架构和交互节奏，但使用 GoJet 自有品牌、文案和资产，不复制第三方受保护的品牌素材。

核心产品入口：

- URL Shortener
- Analytics
- QR Code
- Link in Bio
- Text Sharing
- File Sharing
- Custom Domains

## 发布门禁

新的候选版本必须同时通过：

1. Go 单元测试与 `go vet`。
2. 八个生产服务编译。
3. 前端静态语法检查。
4. 全新数据库迁移。
5. 浏览器 E2E：注册、验证邮箱、登录、创建短链、访问、统计、找回密码、重置密码。
6. 管理员 E2E：创建/编辑/封禁用户、权限管理、SMTP、邮件模板、Markdown 公告、缓存、维护模式、审计日志。
7. aaPanel Debian 12 实机全新安装验收。

只有上述链路通过后才生成新的候选生产安装包。
