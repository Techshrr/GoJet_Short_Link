# 管理后台资源与系统运维中心

## 资源隔离与恢复

管理后台统一列出短链接、文本分享、个人主页、二维码和文件分享。管理员必须填写原因才能隔离；隔离会在事务内保存资源原状态并立即停止公开访问。恢复同样必须填写原因，并恢复隔离前状态。文件只有 `scan_status=clean` 时才允许恢复，感染或扫描异常文件不能绕过安全扫描。

每次隔离记录只允许存在一个活动状态，通过数据库生成列和唯一索引防止并发重复操作。短链接隔离和恢复后同步刷新 Redis 跳转记录；所有管理员请求继续写入 `administrator_audit_logs`。

## 用户登录记录

用户会话保存 IP、User-Agent、创建时间、最后活动时间、有效期与撤销时间。后台只展示会话哈希指纹，不保存或显示原始 Bearer Token。管理员可以撤销单个设备会话，用户封禁仍会撤销该用户全部会话。

## 系统诊断

诊断中心读取真实 MySQL 和 Redis 延迟、连接池、Analytics Stream 长度与 Consumer Pending、邮件积压与失败、文件扫描积压、Analytics Worker 失败、有效用户会话和隔离资源数量。

可执行操作均要求原因并进入任务记录：

- 平台对账：处理订阅周期、清理失效会话、重新投递失去租约的文件扫描；
- 缓存清理：只扫描并删除 `gojet:cache:*`，不会删除实时点击、独立访客或 Analytics Stream；
- 维护模式：用户 API 返回 `503` 和 `Retry-After`，健康检查、服务状态及管理员 API 保持可用。
