# 生产日志接收、索引与保留

GoJet 选择内置的 MySQL 结构化日志索引作为默认接收器，避免部署基线强制依赖额外的 Elasticsearch 集群。所有服务继续输出 NDJSON 到标准输出，同时通过带 Bearer Token 的 `LOG_WEBHOOK_URL` 投递到 Log Receiver。

接收器限制单批 1MB、最多 1000 条、单条最多 256KB，并验证时间、服务、级别、事件和关联 ID。记录按时间、服务/级别和 `request_id` 建立索引。默认保留 30 天，管理员可在 1–365 天内调整；接收器每小时分批清理，避免大事务锁表。

管理后台“系统诊断”展示总索引量、24 小时错误数、按小时/服务/级别趋势和当前保留周期。关联 ID 仍可同时查询管理员审计、分析事件与结构化日志索引。

生产环境必须让 `LOG_WEBHOOK_TOKEN` 与接收器的 `LOG_INGEST_TOKEN` 保持一致，并通过内部容器网络访问接收器，不应将写入接口暴露到公网。
