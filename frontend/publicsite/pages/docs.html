开始使用

产品概览

GoJet 把常用的链接与内容分享能力放在同一个工作区中。短链接是核心入口，二维码、访问分析、智能路由等能力可以围绕同一条链接继续扩展。

短链接创建易于传播的短网址，并持续维护目标地址。
二维码二维码跟随短链接，不需要因为目标网址变化反复更换。
文本与文件对临时文字、代码片段和文件提供独立分享入口。
访问分析查看访问次数、访客、来源、地区、设备与浏览器。
开始使用

账户与工作区

注册后系统会为你准备个人工作区。链接、二维码、分享资源、账单和团队成员都归属于工作区，因此切换工作区时看到的内容也会随之变化。

  1. 注册并登录 GoJet。
  2. 进入控制台，确认顶部当前工作区。
  3. 个人使用可以直接保留默认工作区；团队使用可以建立独立工作区并邀请成员。
建议

不同品牌、客户或项目如果需要独立成员与账单，最好使用不同工作区，而不是全部堆在同一个工作区里。

快速开始

创建第一条短链接

  1. 在控制台打开「链接管理」，点击「创建短链接」。
  2. 粘贴完整的目标网址，例如 https://example.com/product。
  3. 选择短链域名。可以使用管理员提供的官方域名，也可以使用自己已经验证的域名。
  4. 短码可以留空自动生成，也可以填写容易记忆的自定义短码。
  5. 一般场景使用 302 临时跳转即可；确实需要永久跳转时再选择 301 或 308。
目标网址→选择域名→生成短码→复制分享
链接与分享

短链接

创建后可以继续修改目标网址、链接名称、跳转方式、访问密码、有效期和访问次数限制。为了避免已经公开的地址失效，编辑时不会直接更换原短码和域名。

常用访问规则

  • 访问密码：适合只希望特定人员查看的链接。
  • 有效期：到期后停止继续跳转。
  • 访问次数上限：达到上限后停止继续访问。
  • 一次性访问：适合临时、单次交付场景。
链接与分享

二维码

二维码基于现有短链接生成。创建时选择链接、名称、尺寸和颜色，生成后可以直接下载图片。

为什么先创建短链接？

二维码里保存的是短链接地址。以后你只需要修改短链接目标，已经印刷或发布的二维码仍然可以继续使用。

链接与分享

文本分享

创建文本时可以自行选择三种展示方式，内容不会因为选择格式而执行脚本。

纯文本保留换行与空格，适合普通说明和临时文字。
Markdown支持标题、列表、引用、链接、粗体、行内代码和代码块等常用排版。
代码使用等宽字体原样显示，适合代码片段、配置和日志。

文本分享还可以设置访问密码、有效期，以及「读取一次后自动失效」。

链接与分享

文件分享

文件上传后先进入安全检查流程，通过检查后才会成为可下载资源。你可以继续设置访问密码、有效期和下载次数限制。

上传→安全检查→可分享→下载统计
链接与分享

个人主页

个人主页适合把多个长期入口汇总到一个页面。可以维护标题、简介、头像、主题和多个外部链接，并保持公开地址长期不变。

域名与分析

官方短链域名

站点管理员可以维护多个官方短链域名，并指定一个默认域名。客户创建短链接时会看到当前可用的官方域名列表，不需要每个客户重复做域名验证。

管理员停用某个域名后，它不会再出现在新建链接的选择列表中；已经存在的链接不会因为「停用」动作被自动删除。

域名与分析

自定义域名

  1. 在工作区打开「自定义域名」，添加需要使用的域名。
  2. 按照控制台给出的验证信息配置 DNS。
  3. 回到控制台执行验证，等待域名状态与 HTTPS 状态均正常。
  4. 创建短链接时即可从域名下拉列表中选择该域名。
注意

只有已经完成所有权验证且 HTTPS 可用的域名才会进入短链接选择列表。

域名与分析

访问分析

每条短链接都可以查看访问表现，包括点击、独立访客、访问来源、国家/地区、设备、浏览器以及最近访问记录。二维码访问也会单独记录，方便区分线上与线下入口。

域名与分析

智能路由与 A/B 分流

高级设置默认收起，普通链接无需配置。需要精细分流时，可以按国家/地区、设备、浏览器语言或访问来源把流量送到不同目标；A/B 分流则按权重把未命中规则的访问分配到多个目标。

账户与服务

团队协作

工作区可以邀请成员，并根据角色控制可执行的操作。成员变更、邀请状态和主要资源都集中在同一工作区管理。

账户与服务

套餐与账单

套餐决定工作区可使用的资源配额。账单页面显示当前订阅、发票与可用支付方式；具体价格、币种与支付渠道以当前站点配置为准。

账户与服务

账户安全

GoJet 可以在注册、登录、找回密码、工单和滥用举报等场景启用 Turnstile 人机验证。管理员还可以管理用户会话和登录安全策略。

账户与服务

支持工单

需要持续跟进的问题建议使用工单。工单会保留主题、部门、优先级、处理状态以及双方回复记录，比一次性的联系表单更适合排查问题。

开发者

API 与自动化

需要把链接管理接入自己的业务流程时，可以使用 GoJet 的接口能力。接口遵循账户和工作区权限边界，建议为自动化操作使用专门的账户与最小权限。

开发者

支付回调与事件

支付渠道的异步回调由服务端接收并校验。正式接入时应使用支付服务商提供的签名验证方式，并以服务端确认结果作为最终支付状态依据。

没有找到答案？
