# API 参考

本页给出 GoJet 核心 API 操作的请求格式和常见响应。示例中的域名和凭据需要替换为你自己的站点与工作区信息。

## POST `/api/links`

使用具备创建短链接权限的 API 密钥，在工作区中创建一条短链接。

**鉴权：** `Authorization: Bearer <API_KEY>`

### 请求体
```json
{
  "destination": "https://example.com/campaign",
  "domain": "go.example.com",
  "slug": "launch",
  "title": "Launch campaign"
}
```

`destination` 是访问者最终需要到达的完整地址；`domain` 与 `slug` 在接口和工作区允许的情况下用于指定公开地址；`title` 是 GoJet 后台中用于识别该链接的名称。

### curl 示例
```bash
curl -X POST 'https://gojet.example/api/links' \
  -H 'Authorization: Bearer YOUR_API_KEY' \
  -H 'Content-Type: application/json' \
  -d '{"destination":"https://example.com/campaign","slug":"launch"}'
```

### JavaScript 示例
```javascript
const response = await fetch('https://gojet.example/api/links', {
  method: 'POST',
  headers: {
    Authorization: `Bearer ${process.env.GOJET_API_KEY}`,
    'Content-Type': 'application/json'
  },
  body: JSON.stringify({ destination: 'https://example.com/campaign', slug: 'launch' })
});
const link = await response.json();
```

### PHP 示例
```php
$ch = curl_init('https://gojet.example/api/links');
curl_setopt_array($ch, [
    CURLOPT_POST => true,
    CURLOPT_HTTPHEADER => [
        'Authorization: Bearer '.getenv('GOJET_API_KEY'),
        'Content-Type: application/json'
    ],
    CURLOPT_POSTFIELDS => json_encode([
        'destination' => 'https://example.com/campaign',
        'slug' => 'launch'
    ]),
    CURLOPT_RETURNTRANSFER => true,
]);
$result = curl_exec($ch);
```

### Go 示例
```go
payload := strings.NewReader(`{"destination":"https://example.com/campaign","slug":"launch"}`)
req, _ := http.NewRequest(http.MethodPost, "https://gojet.example/api/links", payload)
req.Header.Set("Authorization", "Bearer "+os.Getenv("GOJET_API_KEY"))
req.Header.Set("Content-Type", "application/json")
resp, err := http.DefaultClient.Do(req)
```

### 成功响应
创建成功后返回已经保存的链接信息，其中包括资源编号、公开地址、目标地址和当前状态。

```json
{
  "id": "lnk_01",
  "short_url": "https://go.example.com/launch",
  "destination": "https://example.com/campaign",
  "status": "active"
}
```

### 常见错误
- `400`：请求无法解析或缺少必要的结构信息。
- `401`：API 密钥缺失、无效或已经失效。
- `403`：API 密钥有效，但没有所需工作区权限。
- `409`：请求使用的域名、短路径或资源状态与现有内容冲突。
- `422`：提交数据没有通过验证或策略检查。
- `429`：达到当前限流，需要稍后重试。

限流应以当前部署接口实际返回的信息为准，不要在集成中写死一个全局固定次数。

## GET `/api/links/{id}`

API 密钥具备读取权限时，返回指定短链接当前已经保存的信息。

**鉴权：** `Authorization: Bearer <API_KEY>`

### 路径参数
- `id`：GoJet 返回的短链接资源编号。

### curl 示例
```bash
curl 'https://gojet.example/api/links/lnk_01' \
  -H 'Authorization: Bearer YOUR_API_KEY'
```

成功响应包含当前短链接字段。鉴权失败、权限不足、资源不存在或达到限流时，接口可能分别返回 `401`、`403`、`404` 或 `429`。
