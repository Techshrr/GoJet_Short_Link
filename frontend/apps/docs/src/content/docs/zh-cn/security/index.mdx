# 账号与内容保护

本页说明登录、管理员访问、公开目标地址和上传文件相关的保护机制，以及出现提醒或阻止状态时应当如何处理。

## 保护登录会话

为账号使用独立密码，并在站点提供两步验证时启用。部分站点会要求先完成邮箱验证才能进入受保护功能。发现不认识的登录会话时应注销对应会话；怀疑密码已经泄露时立即修改密码。后台管理员使用独立的管理员会话，普通工作区账号已经登录并不代表自动获得后台管理权限。

## 理解权限错误

出现 `403` 表示当前登录账号没有执行此操作的权限。修改网页内容或直接调用接口也不会绕过权限检查，因为服务端会再次验证账号与角色。确实需要权限时，应由工作区所有者或有权限的管理员调整角色。

## 目标地址检测

GoJet 可以根据当前启用的检测方式检查公开目标地址的风险状态。页面应向正常用户说明可以采取的处理动作，但不会暴露可能帮助滥用者规避检测的内部证据。当服务端阻止某个目标地址时，仅修改浏览器表单不能让被阻止内容变成可发布状态。

## 上传文件扫描

上传文件会根据配置的扫描服务经历等待、扫描中、可用、发现风险或错误等状态。文件处于允许状态之前不应对外发布下载地址。如果扫描持续失败，应检查文件 Worker 和扫描服务本身，而不能把“浏览器上传完成”当成“文件已经安全”的证明。

## 滥用举报与安全事件

滥用举报用于记录对公开内容的投诉，安全事件用于记录站点检测到的可疑或高风险活动。有权限的管理员可以查看关联账号或资源、记录调查结果，并执行系统支持的限制或恢复动作。要求填写原因的重要变更应把原因保留到审计记录中。

## 报告安全问题

使用当前 GoJet 站点公布的安全联系渠道。报告中写明受影响地址或功能、复现步骤以及观察到的影响即可。首次报告不要附带密码、API 密钥、会话 Cookie 或与问题无关的个人信息。
