# 自托管安装

自行维护 GoJet 服务器时使用本节。开始安装前准备好 DNS、TLS、数据库、Redis、存储和邮件相关信息，并先确认服务器满足下面的运行要求。

## 服务器要求

使用当前版本支持的 Linux 系统，并准备 Nginx、MySQL 8 和 Redis。本版本的浏览器安装边界需要 PHP 8.3，安装完成后的应用请求由 Go 服务处理。Node.js 用于前端构建，不作为生产环境的请求处理程序。为上传文件、日志和可验证备份预留足够的持久化存储空间。

## 准备 aaPanel 或宝塔面板

创建网站和数据库，并使用独立数据库账号。把网站根目录指向文档规定的 public 目录，为正式域名配置 TLS，同时不要把 MySQL 和 Redis 端口暴露到公网。如果 Redis 不是仅绑定本机回环地址，应按安装要求配置认证后再允许 GoJet 连接。

## 配置 Nginx

由 Nginx 终止 HTTPS，只把文档规定的应用和 API 路径转发给对应服务。只有来自可信代理的代理头才应被信任；上传大小限制需要与你计划允许的文件大小一致；只有带指纹的静态资源才适合长期不可变缓存。账号页面和 API 动态响应不能作为公共静态内容缓存。

## 运行浏览器安装器

PHP 安装器用于收集安装参数、检查前置条件并完成初始化。安装结束后，短链接、工作区和管理员页面等正常 GoJet 请求由已部署服务处理，安装器不会继续作为业务运行时。

## 配置 MySQL 与 Redis

为 MySQL 创建专用数据库用户，并按照迁移和运行时查询所需权限进行授权，同时保留已经验证可以恢复的备份。Redis 会根据部署配置承担缓存、会话或队列相关功能。本机回环 Redis 可以按安装器说明使用本地策略；可被远程访问的 Redis 不能处于无认证状态。

## 启动后台服务、计划任务、邮件和文件扫描

需要的后台服务应交给系统服务管理器或进程守护程序管理，以便异常退出或服务器重启后自动恢复。配置计划任务，测试邮件实际投递，并在开放公共文件分享之前确认文件扫描服务与 Worker 正常。网页能够打开并不能证明异步任务已经正常运行。

## 验证安装结果

官网和帮助文档以静态文件部署；工作区和管理员后台是分别构建的浏览器应用，并通过 API 与 Go 服务通信。正式交付用户前至少测试一次账号登录、工作区访问、管理员登录、短链接跳转、邮件投递以及文件扫描。
