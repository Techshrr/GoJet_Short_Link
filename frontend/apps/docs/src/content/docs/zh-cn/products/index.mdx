# 创建与管理内容

GoJet 把多种对外发布内容放在同一个工作区中管理，域名、权限、推广活动、标签和访问记录不需要分别维护多套系统。根据访问者最终需要看到或下载的内容选择对应类型即可。

## 短链接

需要把较长目标地址变成简洁公开地址时使用短链接。可以选择公开域名与短路径，填写便于后台识别的标题，并按需要设置有效期、访问限制、推广活动、标签以及条件跳转。当内容已经对外发布后，详情页仍会保留当前目标地址、状态、修改记录和访问数据，方便继续维护。

## 二维码

需要让用户通过手机扫描进入内容时创建二维码。选择目标链接，设置尺寸和当前支持的外观选项，确认预览后导出支持的图片或文档格式。二维码通过 GoJet 链接跳转时，扫描访问仍然可以与原目标地址和访问数据关联，不会变成一张完全脱离后台管理的图片。

## 文件分享

需要让访问者直接打开或下载文档时上传文件。可以按当前功能设置有效期和密码保护。文件上传完成后可能仍处于等待扫描状态，在扫描结果允许公开之前不应对外提供下载。如果扫描发现问题，GoJet 会根据文件安全状态阻止公开访问。

## 文本与代码分享

需要发布纯文本、Markdown 或代码但不想单独建立网页时，可以创建文本页面。选择合适的展示方式，并按需要设置有效期、密码或自定义域名。其他程序需要读取原始内容时，可以使用支持的原始文本查看方式，而不是解析格式化页面。

## 个人主页

需要一个适合移动端、可以集中展示多个链接和内容块的公开页面时使用个人主页。可以排列内容块、添加社交链接、设置页面外观、填写标题与搜索信息、绑定域名，并在同一工作区查看访问情况。

## 访问与扫描数据

打开 **数据分析** 后可以按时间范围、内容、域名、推广活动、国家或地区、设备以及来源筛选已记录访问。需要对比两个时间段时使用对比功能，需要进一步处理数据时可以在当前套餐和站点设置允许的情况下导出。如果确实没有访问数据，页面应显示空状态，而不是用示例成功图表代替真实结果。

## 条件跳转

同一个公开链接需要根据访问者情况进入不同目标地址时使用条件跳转。规则可以按照当前支持的国家或地区、设备、语言、来源或 A/B 分流条件进行匹配，并为没有命中任何规则的访问设置默认目标。保存前检查规则，启用后再使用具有代表性的访问条件进行测试。

## 自定义域名

自定义域名用于把 GoJet 公开地址放到你自己控制的主机名下。正常流程是：添加主机名、配置 DNS、执行验证、等待 HTTPS 可用，最后把域名分配给对应内容。域名正在被公开内容使用时应保持所需 DNS 记录，删除或错误修改记录可能导致已经发布的地址无法访问。
