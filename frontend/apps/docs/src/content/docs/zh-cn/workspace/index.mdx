# 工作区与账号设置

工作区用于集中管理同一账号或团队的成员、内容、域名、账单和账号级设置。账号加入多个工作区时，在执行修改之前先确认当前工作区。

## 成员与角色

打开 **成员** 可以查看当前工作区有哪些成员以及每个人的角色。邀请成员时只授予完成工作所需的权限。修改角色或移除成员时，服务端会再次检查当前登录账号是否有权执行该操作，浏览器中是否显示某个按钮本身并不能决定权限。

## 账单、套餐与限额

打开 **账单与套餐** 查看工作区当前套餐、计费周期、账单以及由计费服务返回的使用限额。这里显示的金额和限制应当作为当前账号的实际信息。套餐变更会影响配额或计费日期时，在确认之前先查看生效周期。

## 域名、推广活动与标签

域名决定对外地址使用哪个主机名；推广活动用于把属于同一营销或运营事项的内容放在一起；标签用于更轻量地整理和筛选内容。持续使用统一的命名方式，可以让后续查找相关内容和对比访问数据更容易。

## API 密钥

只有其他程序或脚本需要访问工作区时才创建 API 密钥，并只授予集成真正需要的权限。密钥只在创建时复制并妥善保存到服务端密钥存储或环境变量中，不要放进浏览器代码、截图或公开仓库。不再使用或可能已经泄露的密钥应立即撤销并重新创建。

## Webhook 通知

其他系统需要自动接收 GoJet 事件时配置 Webhook。填写 HTTPS 接收地址、选择需要的事件，并安全保存签名密钥。接收方应验证签名、正确处理重复投递，并在事件已经被可靠接收后再返回成功响应。

## 工作区设置与操作记录

工作区设置会改变当前工作区的默认行为。可能影响既有内容或成员的设置，在保存之前先阅读说明并确认影响范围。管理员或安全相关的重要修改会在当前功能支持的范围内进入活动或审计记录，便于之后确认什么时间由谁修改了什么内容。
