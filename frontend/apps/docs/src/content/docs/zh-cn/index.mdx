# GoJet 帮助与文档

这里按照实际操作任务说明 GoJet 的使用方法，而不是用一句口号概括功能。文档覆盖账号设置、短链接、二维码、文件与文本分享、个人主页、域名、团队协作、访问数据、API 接入以及自托管维护。每一部分都会说明这个功能会改变什么、开始之前需要准备什么，以及保存后应当看到什么结果。

## 从账号和工作区开始

第一次使用时先阅读 **开始使用**。其中依次说明创建账号、登录、进入工作区、发布第一条短链接以及绑定自定义域名的方法，并说明哪些账号状态会阻止操作，例如邮箱尚未验证或当前成员缺少所需权限。

## 创建和管理对外发布的内容

**创建与管理内容** 介绍短链接、二维码、文件分享、文本页面和个人主页，同时说明公开地址、域名、有效期、密码、跳转规则、推广活动、标签与访问数据之间的关系。这样即使内容已经对外发布，后续修改时也能知道具体影响到哪一个地址和哪一批访问。

## 管理成员、账单和账号设置

**工作区与账号设置** 介绍成员、角色、账单、套餐限制、域名、推广活动、API 密钥、Webhook 通知以及工作区设置。当你需要确认某个成员能不能执行操作、某项费用或限额来自哪里、某个资源属于哪个工作区时，应当从这里查找。

## 接入其他系统

**API 与自动化** 说明 API 鉴权、请求规范、Webhook 验签、错误处理与重试方式；API 参考提供具体接口的请求和响应示例。技术性内容集中放在这部分文档中，普通产品页面不再用工程实现术语代替正常功能说明。

## 保护账号和公开内容

**账号与内容保护** 说明登录保护、会话管理、目标地址检测、上传文件扫描、滥用举报和安全事件，并区分“用户可以处理的提醒”和“必须由服务端决定、不能从浏览器绕过的限制”。

## 维护自托管环境

**自托管与维护** 介绍安装要求、Nginx、MySQL、Redis、邮件、文件扫描、后台服务、升级、备份以及回滚方案，适用于自行部署和维护 GoJet 服务器的场景。
