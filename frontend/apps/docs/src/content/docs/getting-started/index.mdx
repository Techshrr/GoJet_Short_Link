# Getting Started

This guide takes you from an empty browser session to a working GoJet workspace with a published short link. Complete the steps in order when setting up a new account.

## Create your account

Open the registration page and enter the display name, email address and password you want to use. Complete the human-verification check when it appears. If email verification is required on the installation, open the verification message before trying to use protected account features.

## Sign in and confirm the account shown

Sign in with your email and password, or with an enabled sign-in provider if the installation offers one. After sign-in, the workspace header should show your actual account name or email. If you are redirected back to sign-in, the session is missing, expired or no longer valid and must be created again.

## Open a workspace

A workspace contains the people, content, domains, billing settings and activity that belong together. New accounts normally begin with a workspace they can use immediately. If you belong to more than one, check the workspace name before creating or editing content so the item is saved to the intended team or account.

## Create your first short link

1. Open **Links** from the workspace navigation.
2. Choose **Create link**.
3. Enter the full destination address, including `https://`.
4. Choose a connected domain when you do not want to use the default public domain.
5. Enter a custom short path if you need one, or allow GoJet to create it automatically.
6. Add a title that makes the link recognizable inside your workspace.
7. Open the additional settings only when you need expiration, access restrictions, routing, campaign assignment or tags.
8. Save the link and open the resulting public address once to confirm it reaches the intended destination.

## Connect a custom domain

Open **Domains**, add the hostname you want to use and copy the DNS record shown by GoJet into your DNS provider. Return to GoJet after DNS has propagated and run verification. Wait until the domain and HTTPS status are ready before assigning the domain to public content. A domain is not ready merely because the DNS form was submitted; the status shown after verification is what determines whether it can be used.

## Where to go next

Use **Create and manage content** for QR codes, files, text pages, bio pages, routing and reporting. Use **Workspace and account settings** when you need to invite people, change roles, review plan limits, create API keys or configure webhook notifications.
