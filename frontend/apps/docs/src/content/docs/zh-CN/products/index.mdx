# 产品

## Links
创建短链并配置自定义域名、状态、过期、访问控制、路由、A/B、活动、标签、分析、版本历史与 API。

## QR Codes
从目标地址或 GoJet 资源创建二维码，配置样式和 Logo、下载支持格式，并在同一工作区查看分析数据。

## Files
上传和分享文件，支持过期/密码控制。文件能否公开下载由服务端扫描与安全状态决定，浏览器不能自行判定“安全”。

## Text sharing
发布纯文本、Markdown 或代码，支持 raw、语法显示、密码、过期和自定义域名。

## Bio Pages
构建移动优先的公开页面，包含区块、社交链接、主题、域名、SEO、分析和安全控制。

## Analytics
查看点击、地区、设备、来源、活动与跨资源活动；保留和导出以部署套餐及隐私策略为准。

## Smart routing
国家、设备、语言、来源、A/B 与 fallback 最终由 Redirect 服务端执行，前端预览不构成路由事实。

## Custom domains
生命周期固定为 **添加 → DNS → 验证 → TLS/状态 → 分配资源**。
