# 工作区与团队

## 导航
一级导航遵循 Overview；Create 下的 Links/QR/Files/Text/Bio；Insights 的 Analytics；Manage 的 Domains/Campaigns/Tags；Developer 的 API Keys/Webhooks；Workspace 的 Members/Billing/Settings，以及 Support。

## Overview
首页优先“创建什么”、最近资源、简洁趋势、需要处理的事项和活动，不做 KPI 卡片墙。

## 成员与角色
邀请成员时明确角色；最终权限由服务端检查，浏览器隐藏按钮不是授权边界。

## 计费与配额
套餐、账单、支付、配额和汇率展示来自服务端计费事实，不复制一套静态价格真相。

## API Key 与 Webhook
API Key 创建时只展示一次，并按约定进行 hash-only 存储；Webhook Secret 创建后写入不可回显，投递带签名且出站请求需要 SSRF 防护。

## 设置与审计
工作区设置和治理动作进入审计上下文；高风险操作按契约要求记录理由与证据。
