# 快速上手

## 创建账号
填写显示名称、邮箱、密码并接受条款；策略需要时完成自适应 Turnstile。受保护的账号流程要求邮箱验证。

## 登录
使用邮箱/密码或后台已启用的 OAuth Provider。会话由服务端管理，不把会话令牌或敏感凭证存入 Web Storage。

## 第一个工作区
工作区是协作与计费边界。先使用默认工作区，再按最小权限原则邀请成员。

## 创建第一条短链
1. 打开 **Workspace → Links**。
2. 点击 **Create link**。
3. 输入目标 URL，可配置短路径。
4. 检查域名、路由、访问控制与过期设置。
5. 创建后验证服务端返回的公开短链。

## 添加自定义域名
添加主机名、按 GoJet 提示发布 DNS 记录、等待服务端验证、确认 TLS/状态，再把域名分配给资源。
