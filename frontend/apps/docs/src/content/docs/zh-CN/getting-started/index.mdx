# 开始使用

本页从没有登录状态开始，一步完成 GoJet 账号、工作区和第一条可访问短链接的创建。新账号建议按顺序完成下面的步骤。

## 创建账号

打开注册页面，填写显示名称、邮箱和密码；出现人机验证时完成验证。如果当前站点要求邮箱验证，应先打开验证邮件完成确认，再进入需要登录保护的账号功能。

## 登录并确认当前账号

使用邮箱和密码登录；如果站点启用了第三方登录，也可以使用已开放的登录方式。登录成功后，工作区顶部应显示当前账号真实的名称或邮箱。如果页面再次跳回登录页，说明会话不存在、已经过期或已经失效，需要重新登录。

## 进入工作区

工作区用来集中管理属于同一账号或团队的成员、内容、域名、账单和操作记录。新账号通常会获得一个可以直接使用的工作区。如果账号加入了多个工作区，在创建或修改内容之前先确认当前工作区名称，避免把内容保存到错误的团队中。

## 创建第一条短链接

1. 在工作区导航中打开 **短链接**。
2. 点击 **新建短链接**。
3. 输入完整目标地址，包括 `https://`。
4. 如果不希望使用默认公开域名，可以选择已经连接并处于可用状态的自定义域名。
5. 按需要填写自定义短路径，也可以让 GoJet 自动生成。
6. 填写一个便于后台识别用途的标题。
7. 只有确实需要时再配置有效期、访问限制、条件跳转、推广活动或标签。
8. 保存后打开生成的公开地址，确认最终到达的页面正确。

## 绑定自定义域名

打开 **域名**，添加需要使用的主机名，然后把 GoJet 显示的 DNS 记录添加到你的 DNS 服务商。等待 DNS 生效后回到 GoJet 执行验证，并等待域名与 HTTPS 状态进入可用状态后再分配给公开内容。仅仅提交了 DNS 表单并不代表域名已经可以使用，必须以验证后的实际状态为准。

## 下一步

二维码、文件、文本页面、个人主页、条件跳转和访问数据请继续查看 **创建与管理内容**。邀请成员、调整角色、查看套餐限制、创建 API 密钥或配置 Webhook 时，请查看 **工作区与账号设置**。
