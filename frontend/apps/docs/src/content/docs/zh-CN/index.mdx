# GoJet Documentation

GoJet 文档是产品工作流、API 集成、安全行为和自托管部署的实施入口。这里保持文档导向，不做营销首页。

## 快速开始
- **快速上手**：创建账号、进入工作区、创建第一条短链并添加自定义域名。
- **产品工作流**：Links、QR Codes、Files、Text、Bio Pages、Analytics、智能路由与域名。
- **开发者**：API 鉴权、核心接口、Webhook、错误与限流。

## 产品区域
Links、QR Codes、Files、Text 和 Bio Pages 共用工作区权限、域名、活动、分析与审计上下文。

## 开发者
使用有范围限制的 API Key、JSON 请求以及签名 Webhook。核心创建短链接口提供 curl、JavaScript、PHP、Go 示例。

## 自托管
覆盖运行要求、aaPanel/宝塔、Nginx、PHP 8.3 安装器边界、MySQL 8、Redis、队列/Worker、Cron、邮件、ClamAV、升级、备份与回滚。
