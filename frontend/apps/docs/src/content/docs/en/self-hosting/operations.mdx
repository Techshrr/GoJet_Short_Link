# Operations, Backup & Rollback

## Health checks
Verify redirect service, platform API, analytics worker/reconciler, file worker, mail worker, operations monitor, log receiver, database, Redis, object/storage backend, and scan service using evidence rather than a hard-coded green dashboard.

## Backup
Back up MySQL and persistent uploaded assets according to your storage backend. Protect encryption material and configuration separately. Test restoration rather than treating backup creation as proof.

## Upgrade
Read release notes, take verified backups, apply migrations once, deploy immutable/static frontend assets, restart required services, and run smoke checks for redirects, auth, workspace, admin, billing callbacks, file scanning, and mail.

## Rollback
Rollback must account for both application binaries/assets and migration compatibility. If a migration is not safely reversible, restore using the documented forward-fix or backup strategy rather than blindly downgrading schema.
