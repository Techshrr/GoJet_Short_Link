# Getting Started

## Create account
Register with your display name, email, password, terms acceptance, and the adaptive Turnstile challenge when required. Verify the email before protected account workflows.

## Login
Sign in with email/password or an enabled OAuth provider. Session state is server-backed; secrets and session tokens are never stored in browser Web Storage.

## First workspace
A workspace is the collaboration and billing boundary. Start with the default workspace, then invite members only with the role needed for their work.

## Create first link
1. Open **Workspace → Links**.
2. Choose **Create link**.
3. Enter the destination URL and optional short path.
4. Review domain, routing, access, and expiry controls.
5. Create the link and verify the generated public URL.

## Add custom domain
Add the hostname, publish the DNS record shown by GoJet, wait for verification, confirm TLS/status, and then assign the domain to resources. Verification is server-authoritative.
