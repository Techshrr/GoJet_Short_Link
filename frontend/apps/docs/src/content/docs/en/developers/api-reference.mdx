# API Reference

## POST `/api/links`

**Authentication:** `Authorization: Bearer <API_KEY>` with a workspace-scoped key allowed to create links.

### Parameters
No path parameters. Optional query parameters are not required for the core create operation.

### Body
```json
{
  "destination": "https://example.com/campaign",
  "domain": "go.example.com",
  "slug": "launch",
  "title": "Launch campaign"
}
```

### Examples

#### curl
```bash
curl -X POST 'https://gojet.example/api/links' \
  -H 'Authorization: Bearer YOUR_API_KEY' \
  -H 'Content-Type: application/json' \
  -d '{"destination":"https://example.com/campaign","slug":"launch"}'
```

#### JavaScript
```javascript
const response = await fetch('https://gojet.example/api/links', {
  method: 'POST',
  headers: { Authorization: `Bearer ${process.env.GOJET_API_KEY}`, 'Content-Type': 'application/json' },
  body: JSON.stringify({ destination: 'https://example.com/campaign', slug: 'launch' })
});
const link = await response.json();
```

#### PHP
```php
$ch = curl_init('https://gojet.example/api/links');
curl_setopt_array($ch, [
    CURLOPT_POST => true,
    CURLOPT_HTTPHEADER => ['Authorization: Bearer '.getenv('GOJET_API_KEY'), 'Content-Type: application/json'],
    CURLOPT_POSTFIELDS => json_encode(['destination' => 'https://example.com/campaign', 'slug' => 'launch']),
    CURLOPT_RETURNTRANSFER => true,
]);
$result = curl_exec($ch);
```

#### Go
```go
payload := strings.NewReader(`{"destination":"https://example.com/campaign","slug":"launch"}`)
req, _ := http.NewRequest(http.MethodPost, "https://gojet.example/api/links", payload)
req.Header.Set("Authorization", "Bearer "+os.Getenv("GOJET_API_KEY"))
req.Header.Set("Content-Type", "application/json")
resp, err := http.DefaultClient.Do(req)
```

### Response
A successful create returns the created link resource with its server-owned identifier, public short URL, destination, status, and timestamps.

```json
{
  "id": "lnk_01",
  "short_url": "https://go.example.com/launch",
  "destination": "https://example.com/campaign",
  "status": "active"
}
```

### Errors
- `400` malformed request.
- `401` missing or invalid API key.
- `403` insufficient workspace permission.
- `409` slug/domain conflict.
- `422` validation or policy failure.
- `429` rate limit exceeded.

### Rate limit
Observe the rate-limit metadata returned by the deployed API and use bounded exponential backoff for `429`. Limits are deployment/plan policy and must not be hard-coded from this example.

## GET `/api/links/{id}`

**Authentication:** bearer token with read access.

### Parameters
- `id` — server-returned link identifier.

### Body
No request body.

### Example
```bash
curl 'https://gojet.example/api/links/lnk_01' -H 'Authorization: Bearer YOUR_API_KEY'
```

### Response
Returns the current server-authoritative link representation.

### Errors
`401`, `403`, `404`, and `429` apply as appropriate.

### Rate limit
Use response metadata; do not assume a universal hard-coded number.
