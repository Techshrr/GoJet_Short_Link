# GoJet Documentation

GoJet documentation is the operational source for product workflows, API integration, security behavior, and self-hosting. It is intentionally documentation-first rather than a marketing surface.

## Start here

- **Quick start** — create an account, enter a workspace, create the first link, and attach a custom domain.
- **Product workflows** — Links, QR Codes, Files, Text, Bio Pages, Analytics, routing, and domains.
- **Developer path** — API authentication, core endpoints, webhooks, errors, and rate limits.

## Product areas

GoJet combines resource creation with control and observability. Links, QR Codes, Files, Text, and Bio Pages share workspace permissions, domains, campaigns, analytics, and audit context.

## Developer

Use scoped API keys, JSON requests, idempotent write patterns where documented, and signed webhooks. The API reference contains curl, JavaScript, PHP, and Go examples for core link creation.

## Self-hosting

The self-hosting guide covers requirements, aaPanel/BT, Nginx, PHP 8.3 installer flow, MySQL 8, Redis, queues, workers, cron, mail, ClamAV, updates, backup, and rollback.
