# Products

## Links
Create short links with custom domains, status, expiry, access controls, routing rules, A/B variants, campaigns, tags, analytics, version history, and API access.

## QR Codes
Build QR codes from a destination or GoJet resource, configure visual treatment and logo, download supported formats, and inspect analytics without separating QR governance from the workspace.

## Files
Upload and share files with expiry/password controls. File availability is gated by server-side scanning and security state; the browser never declares a file clean by itself.

## Text sharing
Publish plain text, Markdown, or code with raw view, syntax handling, password, expiry, and custom-domain assignment.

## Bio Pages
Compose a mobile-first public page with blocks, social links, themes, domain and SEO controls, analytics, and safety controls.

## Analytics
Inspect clicks, geography, devices, referrers, campaigns, and cross-resource activity. Retention and export behavior are bounded by the deployed plan and privacy policy.

## Smart routing
Country, device, language, source, A/B, and fallback rules are evaluated by the redirect service. Client-side UI previews are explanatory only; the server is the decision authority.

## Custom domains
The lifecycle is **Add → DNS → Verification → TLS/status → Assign resources**. Keep DNS examples exact and never treat a UI-only status as proof of verification.
