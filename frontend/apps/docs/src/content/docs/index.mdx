# GoJet Help & Documentation

Use this documentation when you need to complete a task in GoJet rather than guess what a screen or setting means. The guides cover account setup, short links, QR codes, file and text sharing, bio pages, domains, teams, reporting, API access and self-hosting. Each section explains what the feature changes, what information you need before you start, and what result you should expect after saving.

## Start with your account and workspace

If this is your first visit, begin with **Getting Started**. It walks through creating an account, signing in, opening your workspace, publishing your first short link and connecting a custom domain. It also explains which account state can block a task, such as an unverified email or missing workspace permission.

## Create and manage what you publish

The **Create and manage content** guide covers short links, QR codes, files, text pages and bio pages. It explains how public addresses, domains, expiration, passwords, routing rules, campaigns, tags and reporting relate to each item so you can change content later without losing track of what has already been shared.

## Manage people, billing and account settings

The **Workspace and account settings** guide covers members, roles, billing, plan limits, domains, campaigns, API keys, webhook notifications and workspace settings. Use it when you need to understand who can make a change, where a charge or limit comes from, or which workspace owns a resource.

## Connect other systems

The **API and automation** section explains API authentication, request conventions, webhook verification, errors and retry behavior. The API reference includes request and response examples for supported endpoints. Technical examples are kept here so the normal product interface can use clear task-oriented wording.

## Protect accounts and public content

The **Account and content protection** guide explains login protection, session controls, destination checks, uploaded-file scanning, abuse reports and security events. It distinguishes between a warning you can act on and a server-side decision that cannot be overridden from the browser.

## Maintain a self-hosted installation

The **Self-hosting and maintenance** section covers installation requirements, Nginx, MySQL, Redis, mail, file scanning, background services, upgrades, backups and rollback planning. Follow it when you operate your own GoJet server.
