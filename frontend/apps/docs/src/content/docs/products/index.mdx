# Create and Manage Content

GoJet keeps several types of public content in the same workspace so domains, permissions, folders, campaigns, tags and activity do not have to be maintained in separate tools. Choose the content type that matches what you want a visitor to receive.

## Short links

Create a short link when you want a compact public address that forwards visitors to another URL. You can choose the public domain and short path, give the link an internal title, set an expiration time, restrict access, attach campaign or tag information, and add conditional routing when one public address needs to serve more than one destination. The link detail page keeps its current destination, status, history and visit data together so later changes remain traceable.

## QR codes

Create a QR code when people will reach content by scanning a printed or on-screen code. Select the destination link, choose the size and supported appearance options, preview the code, and export a supported image or document format. When the QR code points through a GoJet link, its scans remain connected to the same destination and reporting data instead of becoming an unrelated image file.

## File sharing

Upload a file when the visitor should download or open a document directly. You can add expiration and password protection where available. A newly uploaded file may remain unavailable while scanning is pending. If the scan reports a problem, GoJet keeps the file from being published until the recorded security state allows it.

## Text and code sharing

Create a text page for plain text, Markdown or code that does not need a separate website. Choose the appropriate display mode, add expiration or password protection if required, and assign a custom domain when you want a branded public address. Raw viewing is useful when another program needs the original text instead of the formatted page.

## Bio pages

Create a bio page when you need one mobile-friendly public page containing multiple links and content blocks. Arrange the blocks, add social links, select the page appearance, configure title and search information, connect a domain and review visits from the same workspace.

## Visit and scan reporting

Open **Analytics** to review recorded activity by time range, content item, domain, campaign, country or region, device and referrer. Use comparisons when you need to see how two periods differ, and export records when the installation and plan allow it. If a report has no data, GoJet should show an empty state rather than a sample success chart.

## Conditional routing

Use routing rules when the same public link needs different destinations for different visitors. Rules can consider supported conditions such as country, device, language, source or A/B distribution, with a fallback destination for visits that match no specific rule. Preview the rule configuration before saving, then test representative cases after the rule is active.

## Custom domains

A custom domain moves a GoJet public address onto a hostname you control. The normal sequence is: add the hostname, publish the DNS record, verify the domain, wait for HTTPS readiness, then assign it to content. Keep the domain in DNS while it is in active use; removing or changing the required record can make existing public links unavailable.
