# API Reference

This page shows the request shape and common responses for core GoJet API operations. Replace the example host and credentials with values from your own installation and workspace.

## POST `/api/links`

Creates a short link in a workspace using an API key that has permission to create links.

**Authentication:** `Authorization: Bearer <API_KEY>`

### Request body
```json
{
  "destination": "https://example.com/campaign",
  "domain": "go.example.com",
  "slug": "launch",
  "title": "Launch campaign"
}
```

`destination` is the full URL visitors should reach. `domain` and `slug` identify the requested public address when the endpoint and workspace allow them. `title` is the internal name shown in GoJet.

### curl example
```bash
curl -X POST 'https://gojet.example/api/links' \
  -H 'Authorization: Bearer YOUR_API_KEY' \
  -H 'Content-Type: application/json' \
  -d '{"destination":"https://example.com/campaign","slug":"launch"}'
```

### JavaScript example
```javascript
const response = await fetch('https://gojet.example/api/links', {
  method: 'POST',
  headers: {
    Authorization: `Bearer ${process.env.GOJET_API_KEY}`,
    'Content-Type': 'application/json'
  },
  body: JSON.stringify({ destination: 'https://example.com/campaign', slug: 'launch' })
});
const link = await response.json();
```

### PHP example
```php
$ch = curl_init('https://gojet.example/api/links');
curl_setopt_array($ch, [
    CURLOPT_POST => true,
    CURLOPT_HTTPHEADER => [
        'Authorization: Bearer '.getenv('GOJET_API_KEY'),
        'Content-Type: application/json'
    ],
    CURLOPT_POSTFIELDS => json_encode([
        'destination' => 'https://example.com/campaign',
        'slug' => 'launch'
    ]),
    CURLOPT_RETURNTRANSFER => true,
]);
$result = curl_exec($ch);
```

### Go example
```go
payload := strings.NewReader(`{"destination":"https://example.com/campaign","slug":"launch"}`)
req, _ := http.NewRequest(http.MethodPost, "https://gojet.example/api/links", payload)
req.Header.Set("Authorization", "Bearer "+os.Getenv("GOJET_API_KEY"))
req.Header.Set("Content-Type", "application/json")
resp, err := http.DefaultClient.Do(req)
```

### Successful response
A successful create returns the saved link, including its identifier, public address, destination and current status.

```json
{
  "id": "lnk_01",
  "short_url": "https://go.example.com/launch",
  "destination": "https://example.com/campaign",
  "status": "active"
}
```

### Common errors
- `400` — the request cannot be parsed or a required structural value is missing.
- `401` — the API key is missing, invalid or expired.
- `403` — the API key is valid but does not have the required workspace permission.
- `409` — the requested domain/path or resource state conflicts with an existing value.
- `422` — validation or a policy rule rejects the submitted values.
- `429` — the caller has reached the current rate limit and should retry later.

Use rate-limit information returned by the deployed API rather than hard-coding one universal request count.

## GET `/api/links/{id}`

Returns the current saved representation of a link when the API key has read access.

**Authentication:** `Authorization: Bearer <API_KEY>`

### Path parameter
- `id` — the link identifier returned by GoJet.

### curl example
```bash
curl 'https://gojet.example/api/links/lnk_01' \
  -H 'Authorization: Bearer YOUR_API_KEY'
```

A successful response contains the link's current saved fields. `401`, `403`, `404` and `429` can be returned when authentication, permission, existence or rate-limit checks fail.
