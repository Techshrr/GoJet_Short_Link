## Rules

- Production pages must not hotlink third-party image CDNs.
- Photography must have a traceable source and usage right.
- Product screenshots must come from the current GoJet exact HEAD and must be scrubbed of secrets, internal IDs, debug UI and user-private data.
- Primary raster delivery is AVIF with WebP fallback where needed; SVG is reserved for logos, icons and diagrams.
- Decorative images use empty alt text; meaningful screenshots receive factual UI descriptions rather than keyword stuffing.
